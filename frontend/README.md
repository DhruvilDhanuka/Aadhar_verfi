# Aadhaar Verification — Frontend

A React + Vite application for uploading and verifying Aadhaar card documents against registration details.

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.

> Ensure the FastAPI backend is running on `http://localhost:8000`.
